# Customer Sales and Profit Dashboard

## Project Overview
This project uses Python to analyze sample sales data and visualize business performance through charts and key metrics.

## Objectives
- Calculate total sales and profit.
- Analyze monthly sales trends.
- Compare sales across products and regions.
- Examine product-wise profitability.
- Summarize customer and order performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dashboard Features
- Total sales, total profit, orders, and unique customers.
- Monthly sales trend chart.
- Product-wise sales comparison.
- Regional sales comparison.
- Product-wise profit analysis.

## Dataset
The project uses 500 generated sample orders from 2025. The dataset includes order dates, customers, products, regions, quantities, sales, and profit.

## Conclusion
This project demonstrates how Python can be used to transform sales data into visual insights that support business analysis and decision-making.

*Note: The dataset is synthetic and does not represent actual company transactions.*
